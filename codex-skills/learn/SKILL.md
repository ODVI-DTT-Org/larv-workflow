## larv Headroom Combo

Before context-heavy work, run `bash <larv-plugin-root>/scripts/headroom-combo.sh status "$PWD"` to activate Ponytail + gated Headroom + Caveman. If Headroom falls back, continue normally.

# larv:learn

This is the Codex-compatible entry point for `/larv:learn`.

Read `<larv-plugin-root>/commands/larv-learn.md`, then invoke the `larv-learn` skill from `<larv-plugin-root>/skills/larv-learn/SKILL.md` with the requested flags.
