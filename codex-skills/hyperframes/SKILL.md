# larv:hyperframes

Use the larv HyperFrames promo workflow for the current Laravel app.

Read the core workflow skill at:

```text
<larv-plugin-root>/skills/larv-hyperframes/SKILL.md
```

Then follow it exactly:

- In discovery mode, inspect the app and generate `product-brief.md`, `workflow-summary.md`, `visual-theme.md`, `promo-brief.md`, screenshots or a screenshot plan, and claims needing confirmation.
- Ask for or recommend a video theme before rendering.
- Do not generate the HyperFrames video until the user approves the promo brief.
- In execution mode, use `hyperframes-codex` to validate, render, and report the final MP4.
